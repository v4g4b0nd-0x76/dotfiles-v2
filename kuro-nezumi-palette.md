# Kuro Nezumi

Black/ash-gray is the interface. Warm off-white is readable paper. Red is a signal.

| Token | Hex | Intended use |
|---|---:|---|
| Ink | `#080808` | primary background |
| Ink alt | `#101010` | active line, code background |
| Surface | `#171717` | panels and fields |
| Raised | `#202020` | elevated controls |
| Border | `#343434` | quiet separation |
| Paper | `#D7D2C8` | normal text |
| Soft | `#9A948A` | secondary text |
| Muted | `#6F6A63` | comments and inactive UI |
| Signal red | `#B73535` | active state/action |
| Alert red | `#D94A4A` | errors and urgent attention |
| Moss | `#8A8F73` | success |
| Brass | `#B8A781` | strings/data |
| Steel | `#8C9097` | types/info |
| Oxide | `#7F9693` | functions/hints |
